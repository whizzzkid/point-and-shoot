# Tutorials

A tutorial walks a **person** through one task, start to finish, with the real commands and the real
clicks. It is written for a reader who has never seen this repo and has no reason to read the
source.

Two rules make the difference between a tutorial and a wish:

- **Every command shown has been run**, on the platform stated, at the versions named. A command
  that does not work is worse than no command, because it costs the reader trust as well as time.
- **The sad paths are included.** What the reader sees when the extension cannot attach to a page,
  when a region is clipped by the viewport, when a shadow root is closed, or when an export exceeds
  the size budget. Known limits are documented here up front, not once someone files them as bugs.
